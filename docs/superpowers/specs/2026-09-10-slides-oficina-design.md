# Slides da oficina "Segurança Digital" — desenho

Data: 2026-09-10. Aprovado em chat pelo usuário.

## Objetivo
Apresentação em página HTML única, local (sem hospedar por enquanto), para a oficina
presencial de extensão curricular (Unisanta, ADS). Depois será copiada para a VPS como
site estático, sem alteração.

## Conteúdo (11 slides)
1. Capa
2. Por que falar sobre isso (usos da internet + 3 perguntas para o público)
3. O que a comunidade respondeu (69 respostas em 2 questionários, aplicados junto com
   colegas do curso — redação cautelosa, decisão do usuário)
4. O que é um golpe digital e por onde chega
5. Os golpes que mais aparecem (WhatsApp, PIX, links falsos, promoção falsa, perfil falso)
6. Exemplo "Oi mãe, troquei de número" em bolhas de chat
7. Como perceber que é golpe (5 sinais)
8. Como se proteger
9. Verificação em duas etapas do WhatsApp, passo a passo
10. Dicas rápidas (senha forte, Wi-Fi público, atualizar apps)
11. Para levar para casa + dúvidas

Texto todo reescrito (originalidade), números vindos das planilhas dos formulários
(32 e 37 respostas).

## Visual
Identidade Unisanta: marinho #002F73, azul #0044A9, fundo claro #F3F7FC, vermelho do
brasão #D8232A só para "golpe", verde #1E8E3E só para "proteção". Logo oficial branco
(assets/unisanta-logo-branco.png) no rodapé. Fonte do sistema (Segoe UI/Arial) para
funcionar offline. Ícones SVG inline. Palco fixo 1280x720 escalado ao viewport.

## Navegação
Setas, espaço, PageUp/Down, Home/End, clique nas metades, swipe. F = tela cheia,
? = ajuda. Slide atual no hash da URL. Impressão: um slide por página.

Screenshots de todos os slides via Playwright em 1366x768 e 1024x768.
