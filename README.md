# Slides — Oficina "Segurança Digital" (Extensão Curricular · Unisanta · ADS)

Apresentação em página única para a oficina presencial. Sem dependências: abra `index.html` no navegador.

- Setas / espaço / clique / swipe: navegar · F: tela cheia · P: imprimir (um slide por página) · ?: atalhos
- O número do slide fica na URL (`index.html#6`), então dá para retomar de onde parou.
- Para publicar na VPS: copiar `index.html` e a pasta `assets/` para o diretório do site estático.
